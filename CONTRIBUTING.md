# Contributing to Hami Media

Contributions, bug reports, reproducible benchmarks, and documentation
improvements are welcome.

Before submitting changes:

- Read the README and relevant documentation.
- Check existing issues.
- Explain the problem and expected behavior.
- Keep changes focused.

Run tests:

    go test ./...

Build:

    go build ./...

Performance claims should include reproducible test conditions.
Never submit credentials, private keys, production secrets, or personal data.
