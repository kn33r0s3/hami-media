# Name and trademark check (17.6)

Job 17.6: a written check exists.

Status: **DONE (preliminary check) 25 Nov 2026.** This is a written
check based on public web search. It is not a formal trademark
clearance search, and it says so.

## The names

- **hami-media** — the server in this repo.
- **Hami** — the wider system it belongs to (Nepali हामी, "we").

## What was checked (25 Nov 2026)

Web search for `Hami trademark Nepal "hami-media"` and the project's
own public pages. Findings:

1. **"Hami" is a common Nepali word** (हामी = "we"), used as a name
   by more than one unrelated party. The project's public page
   describes Hami as the system for understanding Nepal's economy.
2. **An unrelated organisation called "Hami Nepal"** (tagline "For
   the people, by the people") appears in Nepali social-media
   coverage in 2025-2026, in a political context. It is not the
   same project, and nothing found suggests it claims the name
   "hami-media" or operates a media server.
3. **No registered-trademark hit for "hami-media"** appeared in the
   search results. Domain-fuzzy listings show many look-alike
   domains (humi.media, haami.io, etc.); none is "hami-media" as a
   product.
4. **No conflicting software project named "hami-media"** was found.

## Conclusion

- No blocker found for using **hami-media** as the server's name.
- The generic nature of "Hami" means the name is weak as a
  distinctive mark: it is descriptive in Nepali, and another Nepali
  organisation already uses it. If distinctiveness matters, a
  compound or qualified name would be stronger — that is a product
  decision, not a legal finding.
- **Owed before commercial use**: a formal search in the Nepal
  trademark registry (Department of Industry) and a domain check
  for hami.media / hami-media, by the owner or counsel. This file
  does not replace that search.
